# Lapnito app documentation status

This repository stores the machine-readable daily status used by the Lapnito documentation pipeline. It compares current Google Play and App Store evidence, public GitHub coverage and locally available app projects, then recommends the next documentation target.

- [`portfolio_status.json`](portfolio_status.json) — latest complete scan and ranked recommendation
- `history/YYYY-MM-DD.json` — one immutable daily snapshot when the observed state changed

The scan is evidence, not a release announcement. Google Play HTML is treated as best-effort, App Store identifiers come from public store links and repository evidence, and an app is never described as published on a platform without a verified listing.

Generated by the `lapnito-docs-daily` Codex skill. Developer: [lapnito.cz s.r.o.](https://lapnito.cz).
